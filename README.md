# 📦 Inventory Pro
A professional logistics and stock management system built with **Python** and **Streamlit**.

### 🚀 Features
* **Live Inventory Tracking**: Real-time updates for stock levels.
* **Automated Alerts**: Visual indicators for low-stock items.
* **Custom UI**: Dark-mode optimized dashboard for professional use.

### 🛠️ Setup
1. Install requirements: `pip install -x requirements.txt`
2. Run the app: `streamlit run Logistics_tracker/tracker.py`
